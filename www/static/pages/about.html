About This Project

This is a test site for the Webserv HTTP server project. The purpose of this site is to test various features of the server, including:

  • Serving static HTML, CSS, and JavaScript files
  • Handling different HTTP methods (GET, POST, etc.)
  • Proper error handling (404, 500, etc.)
  • Directory listing
  • Redirects
  • And more...

The Webserv project is an implementation of an HTTP server from scratch, without using existing HTTP server libraries. It's designed to be compatible with common web browsers and to handle standard HTTP requests and responses.
