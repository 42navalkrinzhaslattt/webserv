Example Virtual Host

This is the example virtual host running on port 8080 with server_name example.local.

Server Information

  • Port: 8080
  • Server Name: example.local
  • Root Directory: ./html/example

Virtual Host Testing

To test this virtual host, add the following line to your /etc/hosts file:

127.0.0.1 example.local

Then access http://example.local:8080 in your browser.
