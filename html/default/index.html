Welcome to Webserv

This is a simple HTTP server implemented in C++98 according to the 42 project requirements.

Features

  • HTTP/1.1 compliant
  • Non-blocking I/O with poll()
  • Support for GET, POST, and DELETE methods
  • CGI script execution
  • File uploads
  • Custom error pages
  • Directory listing
